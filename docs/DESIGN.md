# ArcLike · 日常，自有秩序

已确认的中文侧栏原型与 Chrome 开发版共享同一套布局、样式和安全渲染。选择雾青与暖白，而不是复制 Arc 外观；细线图标、低噪声分隔、少量暖橙与紫色用于入口识别。原型网页区的「山海」是虚构演示，不代表插件可以重绘真实网页；真实扩展只渲染侧栏。真实入口用名称首字作为本地图标，不为识别入口发送 favicon 请求。

## 布局与层级

| 区域 | 用途 | 生命周期 |
| --- | --- | --- |
| 顶部 Favorites / 常用 | 共享工具，图标入口，不随工作区切换 | 关闭页面后保留入口 |
| Space 的 Pinned / 文件夹 | 当前工作区的长期入口；文件夹折叠、改名；新增入口可放入现有文件夹 | 显式移除才删除 |
| Today / 临时页面 | 当前工作区本次浏览的临时集合 | 关闭即移除；可选按闲置时长自动关闭，参数默认 12h，不是午夜清空队列 |
| 底部工作区与设置 | 快速切换、完整工作区列表、重命名 / 新建、轻量设置 | 常驻，不随列表滚走 |

原型宽屏侧栏 286px，独立示意框 320px；≤ 580px 隐去展示页与浏览器示意框。真实 Side Panel 占满 Chrome 分配的宽高，已对 240 / 280 / 320 / 360 / 480 / 600px 的网页视口进行布局自检，不代表原生 Chrome 支持这些面板宽度。列表独立滚动，底部切换器固定；工作区多时图标横向滚动，当前项保持可见。长名称省略显示，窄侧栏「··· / ×」常显，避免依赖悬停。

v0.1.3 的真实侧栏移除插件内重复标题，搜索直接置顶；常用图标采用固定 36px 网格，固定入口空状态仅一行，避免初始化卡片占据整段列表。Chrome 自身的标题与按钮保留，不伪装成可被插件隐藏的元素。默认「日常 / 工作」两区；旧的空默认留白只在没有内容且未改名时移除，旧内容与自定义空间保留。持久标记 `defaultSpacesVersion: 2` 防止后续自定义改名被重复迁移覆盖。

原生侧栏外框只能由 Chrome 调整，内容始终 `width: 100%; min-width: 0`。不使用 CSS max-width 或自造拖拽柄留下空白外框；原生最小宽度与分隔线拖动依据见验证记录。

## 核心交互：入口不是页面

状态分为两部分：

```text
Favorite / Pin: { id, title, homeUrl, folderId, icon, iconGlyph?, color }
原型 live[id]: { url }
扩展 live[id]: { tabId, url }
Space: { activeId, pins, folders, today }
```

- **点击固定入口**：未加载时用 `homeUrl` 打开；已加载时选中现有页面，保留当前导航地址，不重复创建。
- **导航**：只改变 `live[id].url`，`homeUrl` 不随导航覆盖。原型用模拟地址栏 / 子页面验证；扩展由原生 tabs 事件更新。
- **返回固定起点**：显式导航回 `homeUrl`。原型网页工具条有快捷入口；真实扩展通过条目菜单操作，不向网站注入按钮。
- **关闭 ×**：删除活页面绑定；Favorite / Pin 仍在。再次点击按保存的起始 URL 重开。
- **移除固定入口…**：独立、需要确认的删除动作。如果页面还开着，转入当前 Space 的 Today，不静默关掉页面；未加载入口则直接移除。
- **固定临时页 / 拖动**：Today 可拖到 Pinned、文件夹标题或 Favorites 区域；绿色边框标明接收区域。保存真实当前 URL，保留实体 ID / tab ID，不关闭或重开网页；晋升后移除临时计时属性。菜单提供固定 / 设为共享常用入口的键盘替代。只接受本侧栏当前 Space 的内部拖动，外来 URL / HTML 和过期拖动不保存；后端再次验证工作区、实际页面、地址与文件夹。
- **排序**：菜单「向上 / 向下」在同一层级 / 文件夹内交换，首尾动作禁用。拖动仅负责临时页晋升，没有额外引入列表拖放排序。
- **工作区切换**：切换组织与记住的已打开页面，不隐藏 / 关闭其他工作区的原生标签；Favorites 共享。原生栏激活已绑定条目会跟随其所属工作区，但后台标题 / 加载事件不会把用户切回其他工作区。没有登录隔离承诺。
- **重命名**：只改侧栏入口名称，不修改网站或原生标签标题；Today 手动命名后也不会被后续原生标题事件覆盖。

- **更换图标**：Favorites 右键 / Shift + F10，或条目「···」打开共用编辑对话框。11 个本地 SVG、名称首字、自定义单个可见字 / emoji 与五种色系；实时预览、保存或取消。自定义用 `Intl.Segmenter` 校验一个字素簇，支持旗帜、肤色与组合 emoji；最长 32 个 UTF-16 单元，拒绝空白 / 控制字符。文本转义而非 HTML / 外部图片，不增加权限或请求；emoji 保留自身颜色。只修改实体的 `icon / iconGlyph / color`，不改地址、标题或页面绑定。旧入口无需迁移，选择名称首字会清除自定义值。永久入口图标持久保存，Today 图标只随临时实体存在，晋升后一起保存；过期跨区编辑拒绝，保存失败保留草稿。

## 状态与可访问性

- 相邻页面：固定区、文件夹内与 Today 使用 1px 水平渐变分割线，中间稍深、两端透明，颜色随主题；不增加行高、不拦截点击或拖动，列表首尾不额外画线。
- 选中：浅色卡片与左侧短标记；Favorite 有选中边框，按钮带 `aria-pressed`。
- 未加载：空心点、弱化图标、标题提示；不是失效或被删除。
- 悬停 / 焦点：轻色背景与操作露出；键盘焦点 2px 描边，重绘后恢复对应入口焦点。
- 空工作区：保留层级，提供「添加第一个入口」；网页区不伪造已打开页面。
- 关闭 / 删除：不同文案、不同按钮，删除确认明确说明页面去向；短提示不阻挡底部切换器。
- 原生模态对话框管理焦点；关闭后返回触发位置。支持 `/`、Tab、Esc、Shift + F10、菜单方向键 / Home / End。浏览器快捷键或原生激活导致工作区 / 管理窗口改变时，关闭过期菜单并取消未提交的侧栏对话框；界面请求携带工作区 ID，后端拒绝切区后的延迟提交和跨区排序，纯模型对过期排序无操作，避免污染 Today。
- 扩展另有三个浏览器级命令：同键打开 / 关闭侧栏、前 / 后工作区（默认组合见 README）。开关使用 Chrome 原生扩展按钮动作，由浏览器真实可见性决定，不维护易失真的可见性标记；切区复用原有串行 switch 路径，首尾循环，侧栏关闭时也可用。
- 手工添加 / 固定只接受 http / https，拒绝空白名称；扩展还拒绝 URL 中的用户名 / 密码。原生内部页面可临时管理，但不能固定。用户文本转义后进入严格允许列表的惰性 DOM 片段，不接纳脚本、事件属性或外部资源节点。
- 支持自动 / 雾青 / 松夜 / 暖沙 / 海盐 / 暮紫六种外观与紧凑列表；遵循减少动态效果偏好。自动模式随浏览器浅 / 深色偏好切换，使用系统界面色，不重绘 DOM，因此保留焦点与编辑中的输入。手选外观固定，旧选择保留。Chrome 没有读取自定义主题色或背景图的公开扩展 API，不承诺商店主题一比一适配。没有添加账号、同步、自动归档或复杂主题编辑器。

## 自动过期：明确启用，不伪装成安全归档

持久设置 `expiryEnabled: boolean` 与 `expiryHours: 1–720`（整数），分别默认 false 与 12。开关与参数独立，关闭保留时长。旧 0 / 24h 数据迁移为 false / 12 与 true / 24，保留已有开启规则与主题选择。启用或缩短已开启的时长需单独确认真实关页与未保存内容风险；可能立即清理已超时页面，取消不改原值。开启时列表底部显示配置的小时数。会话内 Today 保存 `lastActiveAt` 毫秒时间戳，`lastActiveId` 跟踪实际使用 / 离开，独立于各 Space 记住的 `activeId`；这些计时信息不进入持久备份。后台标题变化不续期，旧会话没有时间戳时从升级时刻起算。

Chrome Alarm 每 5 分钟检查所有工作区的 Today，仅关闭管理窗口内过期页面。当前 / 原生固定 / 发声 / 加载 / 不允许自动丢弃的页面跳过；检查期间收到激活事件会放弃该次关页。固定 / 常用入口不参与过期；显式移除固定入口转 Today 后重新起算。关闭失败保留入口，可重试；不会关闭移到另一个窗口的页。站点没有内容访问权限，不能可靠检测未保存编辑，因此不提供默认自动关闭或“无损归档”承诺。

Alarm 只在启用时存在，关闭时清理；Worker / 浏览器启动重建丢失的 Alarm，不重置现有下次执行时间。Worker 唤醒的配置读取不扫描 / 关闭页面，避免抢先清除尚未处理的原生替换 ID。真实 Alarm 调度可能延后；浏览器会话清空后不自动匹配旧网页。

## Chrome 接入边界

开发版 v0.1.6（保持 Chrome 141+ 支持基线）已有 `manifest.json`、真实侧栏、后台 Worker 与 tabs / storage 接入：

- `ui.js` / `model.js` 共用呈现与纯状态规则；`app.js` 继续提供独立的虚构演示。原型存储键 `arclike.prototype.v1` 不影响 Chrome 扩展数据。
- `extension/background.js` 同步注册事件与 `chrome.commands.onCommand`，允许 Chrome 唤醒 Worker；界面消息只接受自身侧栏来源。`_execute_action` 绑定开关快捷键，配合 `openPanelOnActionClick: true` 交给 Chrome 原生切换，不经自定义 onCommand / 存储等待；鼠标关闭、其他面板切换或 Worker 休眠不会留下自定义开关标记。`extension/controller.js` 把界面命令和原生事件排入同一个串行队列。
- 入口使用独立 UUID，只按真实 tab ID 绑定，不根据同 URL 猜测归属。原生关闭、移动出管理窗口、ID 替换都有对应处理；创建 / 激活 / 导航失败不会被显示为成功。
- `arclike.data.v1` 写入 `chrome.storage.local`，保存入口、起点、文件夹、工作区和设置；`arclike.session.v1` 写入 `chrome.storage.session`，保存窗口归属、Today 和真实绑定。持久数据损坏不静默重置；删除入口先完成持久写入。
- 同一扩展会话内 Worker 重建可恢复绑定。浏览器重启或扩展重新加载后，只恢复持久入口，不自动匹配 Chrome 恢复的页面；手动纳入只把现有页放进 Today。
- 首版一个普通窗口，接管另一个窗口需要确认，释放旧临时归属但不关闭旧页面。连续多窗口上下文、备份导入、拖放排序和关闭页归档恢复暂未实现。

API 模拟器和真实 Chrome DOM 已覆盖核心交互与失败路径，但实际扩展加载、授权、Side Panel 外层和原生 Worker 休眠尚待手动验收，不能把模拟结果等同于这些检查已通过。

Chrome 原生框架与标签栏不在插件自由定制范围内。逻辑 Space 不提供 Cookie / 登录隔离；账号和云同步后续再考虑。ArcLike 是独立实现，不声称与其他扩展或 Arc 完全等价。
